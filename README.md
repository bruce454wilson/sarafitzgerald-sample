# sarafitzgerald.com — sample conversion

A practice copy of Sara Fitzgerald's GoDaddy site, rebuilt as a Jekyll site on GitHub Pages.
All of Sara's wording is copied as-is; only the layout and styling are new.

Sample notes:
- Images are still loaded from GoDaddy's image server; a real move would copy them into `assets/images`.
- The contact form isn't connected (it needs a free Formspree form ID).
- `robots.txt` and a `noindex` tag keep search engines away while this is a sample.
- See MAINTENANCE.md for how updates work.
